# Examples

## `cascade-guard.yaml`

A fully commented policy file: thresholds, runtime-guard settings, baseline
gating, and auditable suppressions. Copy it next to your pipeline and run:

```bash
cascade-guard policy validate examples/cascade-guard.yaml
cascade-guard policy show examples/cascade-guard.yaml
```

## `langgraph_updates.jsonl`

A small LangGraph-style trace in `stream_mode="updates"` shape: three agents
debate an answer, two converge on the wrong one, and the third capitulates
without new evidence. Analyze it with:

```bash
cascade-guard analyze examples/langgraph_updates.jsonl --wrong-answer "blue" --out report.html
```

## The bundled demo

The canonical labeled scenario ("three agents debate, two gang up on the
correct one") is generated by the CLI itself so it always matches the installed
version:

```bash
cascade-guard demo --dir demo_output
```

It emits the generic-format trace, the HTML report, and the JSON report, and
prints the console summary. Expected findings: one unsupported flip by `alice`
(held `green` for 2 turns, folded to the `blue` majority), wrong answer `blue`
introduced by `bob` with 100% downstream infection, and one output-token spike.

## Producing traces from your own LangGraph app

```python
import json

with open("trace.jsonl", "w") as f:
    for update in graph.stream(inputs, stream_mode="updates"):
        f.write(json.dumps(update, default=lambda o: o.dict()) + "\n")
```

If your framework isn't supported yet, emit the generic format instead — one
JSON object per line with `agent` and `content` (see the README for optional
fields).
